# FHD NPC AI — Space Rangers HD

Модификация искусственного интеллекта NPC для **Space Rangers HD: A War Apart**.

## Текущая публикуемая версия

**v2.2.5 — PERSONALITY_AND_CLAIMS (TEST)**

Версия предназначена для `Rangers.exe` **2.1.2500** (SHA-256: `e43a4b15503c705eebe2d8ce5778c2a2fb090db515a3fd86d319e5c5aa692ebf`). Сборка тестовая; наличие автоматических проверок не заменяет испытания в самой игре.

### Изменения v2.2.5

- В дополнительной информации о корабле добавлено пробное отображение характера пилота и двух ведущих черт.
- Требование компенсации за подбор или уничтожение предметов теперь зависит от характера и отношения пилота к игроку.
- При первом отказе платить устранён скачок отношения напрямую с «Нейтрального» во «Враждебное»: переход происходит через «Плохое».
- Сохранены изменения предыдущих версий: социальная память, реакция свидетелей, сообщения о нападениях, коррекция поведения мирных и военных кораблей.

Подробности: [история изменений](docs/CHANGELOG_2.2.5_RU.txt).

## Установка

1. Скачайте оригинальный ZIP из каталога [releases/v2.2.5](releases/v2.2.5).
2. Распакуйте его в корень игры **с сохранением структуры папок**: внутри архива путь начинается с `Mods/FHD_MODS/FHD_NPC_AI/`.
3. Включите `FHD_NPC_AI` в менеджере модов игры.
4. Используйте только совместимую версию `Rangers.exe`. Сделайте резервную копию сохранений.
